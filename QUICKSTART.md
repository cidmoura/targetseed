# 🚀 Início Rápido - PIL

## Execução Direta (Sem Servidor)

Você pode usar a PIL diretamente no navegador sem instalar Node.js ou servidor:

### 1. **Abrir Diretamente**
1. Faça download ou clone este repositório
2. Abra o arquivo `index.html` diretamente no seu navegador
3. Configure sua chave da API OpenAI quando solicitado

### 2. **Configurar API OpenAI**
1. Acesse [OpenAI Platform](https://platform.openai.com/)
2. Crie uma conta ou faça login
3. Vá em "API Keys" e gere uma nova chave
4. Copie a chave (começa com `sk-...`)
5. Cole na plataforma quando solicitado

### 3. **Testar com Exemplos**
1. Use os **Exemplos Práticos** na interface
2. Clique em qualquer exemplo para preencher automaticamente
3. Clique em **"Gerar Documento"**
4. Aguarde o processamento (15-30 segundos)

## Execução com Servidor (Recomendado)

Para funcionalidades avançadas como logs de auditoria:

### 1. **Instalar Node.js**
- Baixe em [nodejs.org](https://nodejs.org/)
- Instale a versão LTS (recomendado)

### 2. **Instalar Dependências**
```bash
npm install
```

### 3. **Executar Servidor**
```bash
npm start
```

### 4. **Acessar**
Abra: `http://localhost:3000`

## 🆘 Problemas Comuns

### **Erro de CORS**
- Use o servidor Node.js (`npm start`)
- Ou use um servidor local simples

### **API Key Inválida**
- Verifique se a chave está correta
- Confirme se tem créditos na conta OpenAI
- Gere uma nova chave se necessário

### **Documento Não Gera**
- Verifique sua conexão com internet
- Confirme se todos os campos obrigatórios estão preenchidos
- Tente novamente após alguns segundos
